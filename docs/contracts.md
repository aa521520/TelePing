# Internal contracts

State is a JSON-compatible dict. Keys: version=1, interval_minutes=30, last_update_id=-1, targets=list[str] (canonical entry URLs), forced_targets=list[str], force_all=false, pending_targets=list[str], last_check_started=0.0 (UTC unix seconds), site_states=dict[str,dict], expiry_cache=dict, outbox=list[dict], last_summary=dict, menu_registered=false. BASIC_DOMAINS only initializes missing state. All state is encrypted externally.

`teleping.targets.normalize_target(value: str) -> str` normalizes bare domains to http entry URLs, rejects credentials, non-http(s), fragments and non-public literal IPs/localhost. Preserve explicit HTTPS, ports and paths. `parse_targets(text: str) -> list[str]` accepts newline-separated entries, skips blank/comment lines, deduplicates, raises ValueError with a constant non-sensitive code on malformed input.

`teleping.bot.COMMANDS: list[dict[str,str]]` is Telegram setMyCommands payload (command names have no slash). `handle_update(state: dict, update: dict, *, chat_id: int, admin_ids: set[int], bot_username: str = '') -> list[str]` mutates canonical state and returns private reply texts. The caller MUST obtain admin_ids from a fresh Telegram getChatAdministrators lookup for each command, never a static whitelist. It never calls network, logs or saves. It ignores unauthorized messages and wrong @bot mentions, supports /start and /help as help, /settings, /status, /interval N, /add URL, /addmany\nURL\nURL, /list, /delete URL, /check, /checkone URL. Incoming updates advance offset in orchestration, not handler. /check sets force_all, /checkone appends forced_targets; /add[ many] updates targets; /delete removes target, pending and forced references. /addmany with no arguments explains how to send command+list in one message. Refuse a batch atomically if any entry invalid. Messages contain no bot secrets. API use and chunking belong to orchestrator.

`teleping.checks.check_batch(targets: list[str], *, concurrency: int = 5, timeout: float = 45, settle: float = 15, deadline: float | None = None) -> list[dict]` is async. Deadline uses UTC unix seconds. Results per checked target: target:str, status:'ok'|'failed'|'unconfirmed'|'unmeasured', reason:constant code, final_url:str, elapsed_ms:int, http_status:int|None, redirects:list[str], https_hosts:list[str], entry_https:str. Sensitive result data must never print. Blocking private/loopback destinations is production default; tests may inject explicit loopback support. No environment secrets inherited by launched browser.

`teleping.expiry.check_expiry(target: str, https_hosts: list[str], *, now: float | None = None) -> dict` is async and returns domain:{status:'ok'|'unknown',expires_at:ISO-or-null,days:int-or-null}, certificates:list[{host,status:'ok'|'expired'|'unknown',expires_at,days}]. External errors must be constant codes, never logs. Orchestration owns daily caching and warning thresholds.
