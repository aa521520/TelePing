# 17CE 独立机器人使用说明

这是同一个群里的第二个机器人，专门使用 **17CE 官方 API** 检测。它拥有独立的网址清单、检测频率、默认线路和 API 配置。普通网站检测仍由原机器人运行。

17CE API 尚未配置时，可以先管理清单、保存线路和设置；实际检测需要开通官方 API 并填写账号和 API Token 后使用。机器人默认每 1440 分钟检测一次，费用上限按用户要求设为无上限；自动检测需确认启用，启用页会展示当前默认线路。

## 群里的操作

机器人会在群里发送功能面板。只有群里当前的群主和管理员能操作，每一步都重新核验身份。点按钮后填写内容或选择设置，最后确认后执行；输入提示只属于发起操作的人，10 分钟后失效。

同群中发送一次 `/menu`，会同时打开普通检测和 17CE 两个机器人的菜单。只打开 17CE 菜单可发送 `/menu@apiopen17cebot`。其他手动命令仍请带这个机器人的名称，例如 `/status@apiopen17cebot`，以便明确交给 17CE 机器人处理。功能按钮和回复输入提示可以直接使用。

| 功能 | 使用方式 |
| --- | --- |
| 批量添加 | 回复输入提示，每行一个网址 |
| 删除域名 | 每行一个网址，可一次删除多条，同时取消相应排队请求 |
| 查看清单 | 确认后查看这台机器人的独立清单 |
| 检测全部 | 选择本次运营商、大区/省份、节点类型和每地区节点数，再确认 |
| 检测单个 | 填一个网址，选择本次线路，再确认；不加入长期清单 |
| 批量检测 | 每行填一个网址，选择本次线路，再确认；不加入长期清单 |
| 检测频率 | 默认一天一次，可以修改间隔 |
| 每日默认通道 | 保存定时检测使用的运营商、地区、节点类型和节点数 |
| 自动检测 | 展示当前配置后，确认启用或暂停 |
| API 设置 | 打开管理员专用的机器人私聊入口，修改官方账号和 API Token |
| 状态、帮助 | 查看配置状态和操作说明 |

批量输入会忽略空行、合并重复网址；有格式错误时整批不修改。单独检测和批量临时检测不会自动加入长期清单。本次手动选择的线路不会覆盖每日默认设置。

默认通道预设为大陆、电信/联通/移动、IDC 节点、每地区 1 个节点。可以在启用前修改。这里的“每地区 1 个”是 17CE 的分配参数，不能理解为整个域名总共只测 1 个节点；实际节点数由官方服务分配。找不到节点时不会自动扩大地区重新收费检测。

## 私下修改 API

在群里点“API 设置”，再打开提示中的私聊链接。机器人只允许发起设置的同一位群主管理员继续，依次填写 **17CE 官方用户名** 和 **API Token**，最后确认保存。填写过程中不会在群里显示凭据；机器人会尽力清理私聊中提交的凭据消息，且不回显 Token。

这里修改的是官方 API 的账号凭据。第三方接口、自定义服务地址和普通网站机器人 Token 不属于此入口。使用官方控制台的 API Token，不要填写账号登录密码。

更换凭据后，已经被执行程序领取但尚未提交的旧配置任务会取消；还在等待领取的队列会使用新账号继续。已提交给 17CE 的任务可能继续完成。自动检测需要重新确认启用；正在选择线路的旧确认会失效。清单和历史保存在独立的加密存储中。

## 检测通知与费用

一次“检测全部”、单个/批量检测或每日自动检测，各自算一轮。即使网址很多、后台分成多个任务运行，仍在整轮结束后发送一份汇总：显示总数、正常、节点异常、结果不完整、检测失败、待确认、取消和待测数量，以及线路和节点统计。正常网址不逐条列出；异常网址另附简短明细。明细太长会自动分成多条，带同一轮次编号。

报告底部显示**本轮费用参考估算**：优先按 17CE 受理回执中的分配节点数计算，默认参考价为每节点每次 **0.01 元**。失败或超时的节点不会自行按免费扣除。举例：一轮合计分配 300 个节点，参考估算为 3 元；一个网址可能分配多个节点，不是一个网址固定 0.01 元。[17CE 官方 API 说明](https://api.17ce.com/site/api.html?lang=zh_cn)

这不是实际扣费，实际价格、计费及结算以 17CE 账号控制台为准。没有受理回执时，只按已收到的节点给出**不完整估算**，同时标明还有多少项费用待核实；完全没有可核对节点时显示费用待核实。分配数与结束回执矛盾、缺少节点结果等情况不会报告为全部正常。

分页明细底部重复的是**同一轮总估算，各页金额不能相加**。认证失败导致整轮暂停时，可以先收到一份标明“部分汇总”的报告，剩余任务保留；恢复完成后再发最终汇总。

目前官方公开资料未找到可验证的实扣、累计费用或余额查询接口，因此已去掉余额和“暂不可查询”的重复占位。普通菜单、操作回复也不再附这些内容。以后若官方提供正式账务协议，可以再接入真实账单。

任务提交后断线或超时，机器人可能无法知道官方是否已经受理或扣费。这类任务会标为“待核实”，不会自动再次提交收费；可根据任务编号到官方后台核对，再决定是否手动重新检测。

## 部署配置

使用独立的 `cloudflare17ce/wrangler.jsonc` 和 `17ce.yml` 工作流；保留原机器人的服务与密钥。两台 Worker 通过仅支持打开菜单的 `PEER_MENU` 服务绑定联动；部署入口为 `entry.mjs`，具体顺序见[菜单联动说明](menu-sharing.md)。

| 配置 | 放置位置 |
| --- | --- |
| `TELEGRAM_BOT_TOKEN`、`TELEGRAM_CHAT_ID` | 17CE Worker 机密 |
| `STATE_ENCRYPTION_KEY` | 17CE Worker 机密，独立于原机器人的密钥 |
| `WEBHOOK_SECRET`、`RUNNER_API_TOKEN` | 17CE Worker 机密，分别独立生成 |
| `GITHUB_DISPATCH_TOKEN` | 17CE Worker 机密，仍只需本仓库 Actions 读写权限 |
| `GITHUB_REPOSITORY`、`WORKFLOW_FILE=17ce.yml`、`WORKFLOW_REF=main`、`BOT_USERNAME` | 17CE Worker 普通变量 |
| `REFERENCE_NODE_PRICE_MICRO` | 可选的 17CE Worker 普通变量，参考单价，单位为百万分之一元；默认 `10000` 即 0.01 元，每轮创建时固定 |
| `SEVENTEEN_STATE_ENCRYPTION_KEY`、`SEVENTEEN_RUNNER_API_TOKEN` | GitHub Actions Secrets，与 17CE Worker 对应值一致 |
| `SEVENTEEN_API_URL` | GitHub Actions Variable，17CE Worker HTTPS 根地址 |
| `SEVENTEEN_ENABLED=true` | GitHub Actions Variable，开启每小时一次的后备唤醒；实际检测仍遵守机器人设置的频率和 API 就绪状态 |

测速账号和 API Token 通过管理员私聊流程录入后加密保存。GitHub 运行器只在执行时取得加密计划，在内存里解密；不保存明文附件，不输出网址、账号、密钥或原始 API 异常。

API 尚未开通期间，只能验收清单、交互、权限、调度的就绪判断以及模拟接口测试，不能将其称为真实 17CE 测速或真实账单验收。
